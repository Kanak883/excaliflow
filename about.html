Excaliflow: A Free Online Diagram Maker

Excaliflow is a browser-based diagramming tool for creating hand-drawn diagrams, flowcharts, architecture diagrams, and animated causal flows. Draw and customize your ideas directly in your browser without installing desktop software.

Open the Excaliflow editor →

What can you create with Excaliflow?

Use Excaliflow to turn ideas and complex systems into visual explanations. It is useful for planning workflows, illustrating software architecture, explaining processes, and presenting cause-and-effect relationships.

  • Flowcharts and decision diagrams
  • Software architecture and system diagrams
  • AI agent workflows and RAG pipeline diagrams Learn how to draw an AI agent workflow diagram
  • Animated causal flow visualizations
  • Concept maps and freehand sketches

Key features

Excaliflow provides drawing tools for shapes, arrows, text, freehand sketches, and sticky notes. Customize colors and fills, organize work across canvas tabs, and export diagrams as PNG images or WebM video recordings.

You can also save and import supported diagram files, including Excaliflow and Excalidraw formats.

How to use Excaliflow

  1. Open the online diagram editor.
  2. Choose a drawing tool or start with a template.
  3. Add shapes, connect them with arrows, and label your ideas.
  4. Customize the diagram and use the export options to save it.

Does Excaliflow require installation?

No desktop installation is required. Open the website in a compatible browser and start drawing. Your workspace is saved locally in your browser; it is not automatically synchronized between devices or accounts.
